1. Get the application URL by running these commands:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
  {{- range .paths }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}{{ .path }}
  {{- end }}
{{- end }}
{{- else if contains "NodePort" .Values.service.type }}
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "piwigo.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo http://$NODE_IP:$NODE_PORT
{{- else if contains "LoadBalancer" .Values.service.type }}
     NOTE: It may take a few minutes for the LoadBalancer IP to be available.
           You can watch the status of by running 'kubectl get --namespace {{ .Release.Namespace }} svc -w {{ include "piwigo.fullname" . }}'
  export SERVICE_IP=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "piwigo.fullname" . }} --template "{{"{{ range (index .status.loadBalancer.ingress 0) }}{{.}}{{ end }}"}}")
  echo http://$SERVICE_IP:{{ .Values.service.port }}
{{- else if contains "ClusterIP" .Values.service.type }}
  export POD_NAME=$(kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "piwigo.name" . }},app.kubernetes.io/instance={{ .Release.Name }}" -o jsonpath="{.items[0].metadata.name}")
  export CONTAINER_PORT=$(kubectl get pod --namespace {{ .Release.Namespace }} $POD_NAME -o jsonpath="{.spec.containers[0].ports[0].containerPort}")
  echo "Visit http://127.0.0.1:8080 to use your application"
  kubectl --namespace {{ .Release.Namespace }} port-forward $POD_NAME 8080:$CONTAINER_PORT
{{- end }}

2. Piwigo initial setup:
   - Open the application URL in your browser
   - Follow the installation wizard to complete the setup
   - Create your admin account
   {{- if .Values.database.enabled }}
   - Use the following database configuration:
     * Database type: {{ .Values.database.type }}
     * Database host: {{ .Values.database.host }}
     * Database port: {{ .Values.database.port }}
     * Database name: {{ .Values.database.name }}
     * Database user: {{ .Values.database.user }}
   {{- else }}
   - You can use SQLite (default) or configure an external database
   {{- end }}

3. Storage information:
   - Config files are stored in: {{ if .Values.persistence.config.enabled }}PersistentVolume {{ include "piwigo.fullname" . }}-config{{ else }}ephemeral storage (data will be lost on pod restart){{ end }}
   - Gallery images are stored in: {{ if .Values.persistence.gallery.enabled }}PersistentVolume {{ include "piwigo.fullname" . }}-gallery{{ else }}ephemeral storage (data will be lost on pod restart){{ end }}
